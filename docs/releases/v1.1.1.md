# t3onsteroids v1.1.1

Patch release that publishes the **T3 Code 0.1.5 Windows x64 installer** with the t3onsteroids T3 patch series and **T3 Connect enabled**, alongside the `1.1.1` bridge source.

## Windows installer

```text
T3-Code-0.1.5-v1.1.1.20261030.c8cd959156.connect1-x64.exe
```

- Base: T3 Code `0.1.5` (`6d450a4284852af137b2f3407fddd89eb76e7644`).
- Fork: ChatGPT Browser fork at `493e87f8f9`, merged with stable `0.1.5`.
- t3onsteroids patch series: `handoff/t3-patches/main-2026-10-29-6d450a42/` applied with `git am --3way`:
  - `0001` optional per-thread tokens/sec readout;
  - `0002` ACP per-turn token usage from the prompt response.
- T3 Connect: production public configuration baked into the packaged server (`connect1` build):
  - relay `https://relay.t3.codes`
  - Clerk publishable key and JWT template
  - CLI OAuth client
  - `t3 connect status --json` works against the extracted packaged server with no runtime environment variables.
- The installer is **unsigned** and has no auto-update feed.
- The installer does **not** bundle or auto-register the t3onsteroids bridge; the bridge remains the Local ACP provider distributed with this release.

SHA-256: `5F49A4350DA3EF4981BA67FB29F4D95977E4BEC978A52CEE4BAD0B352F9FDF40`

## Bridge

`1.1.1` carries the same bridge implementation as `1.1.0`:

- two concurrent bridged chats (`supportedConcurrency=2`) with the durable profile-wide scheduler;
- workspace and linked-worktree binding;
- model and reasoning selection;
- PNG/JPEG → WebP prompt images;
- background-work projection and report-after-drain follow-ups;
- multiplexed provider event streams;
- durable recovery, drain-aware settlement and bounded polling.

The `v1.0.0` tuple remains the release-qualified support tuple. `1.1.1` remains a feature release on T3 `0.1.5`; `--release-readiness` reports `t3BaselineQualified:false` and `releaseQualified:false` for that baseline until the full V1 matrix is rerun.

## Known limits

- T3 Connect remote linking/relay access was not exercised end-to-end; it requires account authorization and creates a cloud environment.
- The bridge has not been live-qualified over T3 Connect; remote T3 clients remain outside the documented support claim.
- Four- and eight-chat concurrency remain parked.
- The installer is Windows x64 only.
