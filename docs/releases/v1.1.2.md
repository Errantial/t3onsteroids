# t3onsteroids v1.1.2

Patch release on the `1.1.1` feature line that publishes a fresh **T3 Code 0.1.5 Windows x64 installer** with the t3onsteroids T3 patch series and **T3 Connect enabled**, alongside the `1.1.2` bridge source.

## Windows installer

```text
T3-Code-0.1.5-v1.1.2.20261030.e819703412.connect1-x64.exe
```

- Base: T3 Code `0.1.5` (`6d450a4284852af137b2f3407fddd89eb76e7644`).
- Fork: ChatGPT Browser fork at `493e87f8f9`, merged with stable `0.1.5`; build commit `e819703412`.
- t3onsteroids patch series: `handoff/t3-patches/main-2026-10-29-6d450a42/` applied with `git am --3way`:
  - `0001` optional per-thread tokens/sec readout;
  - `0002` ACP per-turn token usage from the prompt response;
  - `0003` show or reload a thread's ChatGPT tab;
  - `0004` keep pinned threads in activity order when the setting is off.
- T3 Connect: production public configuration baked into the packaged server (`connect1` build):
  - relay `https://relay.t3.codes`
  - Clerk publishable key and JWT template
  - CLI OAuth client
  - `t3 connect status --json` works against the extracted packaged server with no runtime environment variables.
- The installer is **unsigned** and has no auto-update feed.
- The installer does **not** bundle or auto-register the t3onsteroids bridge; the bridge remains the Local ACP provider distributed with this release.

SHA-256: `90D2FAF5E1D71246E985AA1C31514BBC580FC91F75B89E0BEF68DDBFA8EA810D` (314,460,876 bytes)

## What changed in 1.1.2

- **Per-thread ChatGPT tab controls.** The thread action menu offers **Show ChatGPT tab** and **Reload ChatGPT tab** for ChatGPT Browser threads. Show focuses the tab through the existing reveal path; Reload forces a cache-bypassing reload of that exact tab. The server resolves the thread's provider session and the conversation of its live operation, so an idle thread with no open tab fails explicitly instead of opening a new conversation.
- **Pinned threads on top is now optional.** A new Settings → General toggle, on by default, keeps the previous behavior. Turned off, pinned threads sort with every other thread by activity and the pinned section disappears; pinning still prevents automatic settling.

The `1.1.1` bridge feature set is unchanged: two concurrent bridged chats, workspace and linked-worktree binding, model and reasoning selection, prompt images, background-work projection and report-after-drain follow-ups.

## Known limits

- T3 Connect remote linking/relay access was not exercised end-to-end; it requires account authorization and creates a cloud environment.
- The bridge has not been live-qualified over T3 Connect; remote T3 clients remain outside the documented support claim.
- The ChatGPT tab controls operate on the live operation's tab; an idle thread has no tab to show or reload and reports that explicitly.
- Four- and eight-chat concurrency remain parked.
- The installer is Windows x64 only.
