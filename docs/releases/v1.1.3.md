# t3onsteroids v1.1.3

Fix release on the `1.1.1` feature line that publishes a fresh **T3 Code 0.1.5 Windows x64 installer** with the t3onsteroids T3 patch series and **T3 Connect enabled**, alongside the `1.1.3` bridge source.

## Windows installer

```text
T3-Code-0.1.5-v1.1.3.20261030.2b0773973df3.connect1-x64.exe
```

- Base: T3 Code `0.1.5` (`6d450a4284852af137b2f3407fddd89eb76e7644`).
- Fork: ChatGPT Browser fork at `493e87f8f9`, merged with stable `0.1.5`; build commit `2b0773973df3`.
- t3onsteroids patch series: `handoff/t3-patches/main-2026-10-29-6d450a42/` applied with `git am --3way`:
  - `0001` optional per-thread tokens/sec readout;
  - `0002` ACP per-turn token usage from the prompt response;
  - `0003` show or reload a thread's ChatGPT tab;
  - `0004` keep pinned threads in activity order when the setting is off;
  - `0005` move the revealed ChatGPT window on-screen.
- T3 Connect: production public configuration baked into the packaged server (`connect1` build):
  - relay `https://relay.t3.codes`
  - Clerk publishable key and JWT template
  - CLI OAuth client
  - `t3 connect status --json` works against the extracted packaged server with no runtime environment variables.
- The installer is **unsigned** and has no auto-update feed.
- The installer does **not** bundle or auto-register the t3onsteroids bridge; the bridge remains the Local ACP provider distributed with this release.

SHA-256: `13340B0C2069D461C671ABA0ABA5C0E0E60B04A5F7486E1A8A1687B3F0C01606` (314,460,406 bytes)

## What changed in 1.1.3

- **Show ChatGPT tab now actually shows it.** The managed worker browser is parked at `-10000,-10000` so it stays out of the user's way; the reveal path activated the tab and focused that off-screen window, so nothing appeared. A reveal now restores a minimized window, moves an off-screen normal window to `80,80`, and focuses it.
- **Reload ChatGPT tab verified.** In a real Chromium with the shipped extension, reload kept the same tab, changed the page's `performance.timeOrigin`, cleared an injected marker, and left the conversation loaded.
- No other behavior changed from `1.1.2`: per-thread ChatGPT tab controls, the pinned-threads-on-top setting, the tokens/sec readout, ACP per-turn usage, and the `1.1.1` bridge feature set are unchanged.

## Known limits

- T3 Connect remote linking/relay access was not exercised end-to-end; it requires account authorization and creates a cloud environment.
- The bridge has not been live-qualified over T3 Connect; remote T3 clients remain outside the documented support claim.
- Four- and eight-chat concurrency remain parked.
- The installer is Windows x64 only.
