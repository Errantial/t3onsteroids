Status: **built and verified, not published.** Build commit `c4965a6ec0e5fd56d3c521453800ba94c64efad5`
(fork `Errantial/t3code`, branch `release/v1.2.2`); full version

(`0517d15c41e95c9d84d8014ae14394ce97bc83f6`, 2,904 commits past the old `0.1.5` baseline), into the

target effort, the SSH remote port range that keeps remote servers off `:3773`, headless remote runtime
sync, the per-thread tokens/sec readout and ACP per-turn token usage.

## What changes for you

- **New base.** Everything upstream shipped in the nightly arrives with it, including the thread
  and sidebar changes, side chats (`/side`, `/btw`), the new voice transcription runtime and the
  compile cache for the server bundle.
- **Tokens/sec readout moved.** Upstream removed the composer context meter. The readout now sits in
  the thread details panel, in the Context section, with its toggle.
- **ACP agents keep their token usage.** Upstream only trusts per-turn counters from agents that
  declare them. This fork keeps reporting them for agents that return them, so the readout works for
  those ACP agents. The upstream test that asserted the opposite was changed to match.
- **Database migrations.** The fork's two migrations (ChatGPT Browser operations, environment roots)
  used ids 73 and 75, which upstream now uses. They run as 90 and 91, are safe to run twice, and a
  reconcile step clears the old fork records first. A copy of server-1's v1.2.1 database upgraded
  through 73-91 cleanly with the new runtime (details in the evidence file). **Updates restart T3**;
  keep the previous runtime directory for rollback as usual.
- **Managed policy** knows the ChatGPT Browser driver, so a policy can allow or deny it.
- **Linux archive is larger** (176 MB, was 121 MB): upstream's voice transcription runtime adds
  53 MB. The Windows installer is 359 MB (was 314 MB) and **unsigned**.

## Checks

Details and counts: `docs/evidence/v1.2.2-release.md`.

- Windows: `pnpm typecheck` and `pnpm lint` pass; the web unit suite (365 files, 5,219 tests),
  client-runtime, evals, the ChatGPT Browser and ACP packages pass. Upstream's own tests that assume a
  POSIX host fail on Windows (server cloud and provider suites, `scripts`, `ssh`, desktop shell
  tests); the same tests pass on Linux.
- Linux (Ubuntu in WSL): typecheck, lint, knip, `release-smoke`, shared, ssh, provider-core,
  provider-acp, ChatGPT Browser, client-runtime, contracts, desktop (118 files), scripts, evals,
  web unit (365 files), mobile (302 files) and the full server suite (509 files) pass, except four
  environment-bound tests: one needs a Playwright browser, one a 4 KiB-page kernel, two assume a
  non-root user.
- The Linux archive (extracted, on server-1) and the Windows server build output start on a scratch
  port with a scratch data directory and report the full version and database migration 91.
